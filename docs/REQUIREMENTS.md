状态：第一版草案，依据 [AGENTS.md](../AGENTS.md) 整理，待 Project Owner 确认。

## 项目定位

AI Developer Hub 是面向个人开发者的 Windows 桌面开发工具箱，用于集中查看和管理本地开发工作信息。项目同时用于练习 Java 桌面开发、Git / GitHub、测试、Code Review、架构设计和多 Agent 协作。

## 目标用户与使用场景

目标用户是需要管理多个本地开发项目的个人开发者。主要使用场景包括查看项目与 Git 状态、记录开发日志和 TODO、访问 AI Agent 入口，以及了解开发环境信息。

## 技术与质量约束

- 目标平台为 Windows，主要技术栈为 Java 21、JavaFX、Maven、JUnit 5；主要 IDE 为 IntelliJ IDEA。
- 按功能组织代码，并保持 UI、Application / Service、Domain、Infrastructure 的职责边界。
- 优先保证可读性、简单性、可测试性和可维护性。
- 不静默吞掉异常；错误应可诊断，UI 不直接展示无意义的底层异常堆栈，不暴露敏感信息。
- 代码任务完成后运行相关测试，不以删除失败测试的方式获得通过结果。
